## 2024-05-23 - MoE Routing Optimization
**Learning:** Significant speedups can be achieved in MoE routing by replacing `argsort` with `jax.lax.top_k` (~18x) and `one_hot().sum()` with `jnp.bincount` (~15x). However, these gains may be masked by inefficient expert execution loops in naive implementations.
**Action:** Always verify micro-benchmarks for component-level optimizations when end-to-end impact is limited by other bottlenecks. Ensure `uv.lock` is not accidentally modified during dependency resolution.
## 2024-04-15 - [Prevent XLA graph bloat by replacing jnp.stack with jax.vmap and hoisting padding]
**Learning:** In JAX, when applying operations like `convolve` independently across a set of channels (e.g., one-hot cluster grids), using a Python loop to stack results (`jnp.stack([... for i in range(N)])`) causes severe XLA loop unrolling and graph bloat, drastically increasing compilation times.
**Action:** Always prefer `jax.vmap` over Python loops for channel-wise operations in JAX. Additionally, hoist operations like `jnp.pad` outside the vectorized function so the entire ND array is padded at once before `vmap` is applied. This keeps XLA graphs compact and yields ~4-5x faster compile times and ~1.2-1.3x runtime speedups.
